It features a chatbot agent to answer queries and provides real-time alerts with location coordinates (longitude and latitude) using Neo 6M hardware with Arduino. Our system leverages AI and analytics to handle multiple camera feeds, developed using Java and TensorFlow. This futuristic software is designed to enhance security and surveillance capabilities, marking a significant milestone in our academic journey
